conexion.php — la conexión a la BD
Un solo fichero con las credenciales. Todos los PHP lo incluyen.
🐘 Regla: crea este fichero PRIMERO, antes de cualquier otro PHP. Si la conexión no funciona, nada más va a funcionar.
conexion.php con PDO
✅ PDO es más seguro, soporta consultas preparadas y funciona igual para MySQL, PostgreSQL, etc. 
<?php
// ═══════════════════════════════════
// conexion.php — incluir en todos los PHP con:
//   require_once 'conexion.php';
//   require_once '../conexion.php';  (si está en subcarpeta)
// ═══════════════════════════════════

define('DB_HOST', 'localhost');     // Servidor (localhost siempre en XAMPP)
define('DB_NAME', 'examen_bd');     // Nombre de tu base de datos
define('DB_USER', 'root');          // Usuario (root en XAMPP)
define('DB_PASS', '');             // Contraseña (vacía en XAMPP por defecto)
define('DB_CHARSET', 'utf8');

try {
    $dsn = "mysql:host=" . DB_HOST . ";dbname=" . DB_NAME . ";charset=" . DB_CHARSET;

    $pdo = new PDO($dsn, DB_USER, DB_PASS, [
        PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
        PDO::ATTR_EMULATE_PREPARES   => false,
    ]);

} catch (PDOException $e) {
    // Si falla la conexión, devuelve JSON de error
    header('Content-Type: application/json');
    http_response_code(500);
    die(json_encode([
        'error' => 'Error de conexión: ' . $e->getMessage()
    ]));
}

APIs PHP — CRUD completo
Cómo escribir clientes.php, polizas.php, etc.
🔌 Patrón: cada fichero PHP recibe la petición de Vue (método HTTP), ejecuta la operación en la BD y devuelve JSON. Siempre empieza con los headers.
clientes.php — estructura base
<?php
// ══════════════════════════════
// clientes.php — API REST para clientes
// ══════════════════════════════

// 1. Headers OBLIGATORIOS — siempre primero
header('Content-Type: application/json');
header('Access-Control-Allow-Origin: *');       // Permite peticiones desde Vue
header('Access-Control-Allow-Methods: GET, POST, PUT, DELETE, OPTIONS');
header('Access-Control-Allow-Headers: Content-Type');

// Responde al "preflight" OPTIONS del navegador
if ($_SERVER['REQUEST_METHOD'] === 'OPTIONS') { exit(0); }

// 2. Incluir la conexión
require_once 'conexion.php';

// 3. Obtener el método HTTP y el cuerpo de la petición
$method = $_SERVER['REQUEST_METHOD'];
$input  = json_decode(file_get_contents('php://input'), true);
$id     = $_GET['id'] ?? null;

// 4. Enrutar según el método
switch ($method) {
  case 'GET':    getClientes();  break;
  case 'POST':   createCliente($input); break;
  case 'PUT':    updateCliente($input, $id); break;
  case 'DELETE': deleteCliente($id); break;
  default:
    http_response_code(405);
    echo json_encode(['error' => 'Método no permitido']);
}

// === FUNCIONES ===
GET — leer todos / uno
function getClientes() {
  global $pdo, $id;

  if ($id) {
    // Obtener UN cliente por ID
    $stmt = $pdo->prepare('SELECT * FROM clientes WHERE id = ?');
    $stmt->execute([$id]);
    $cliente = $stmt->fetch();

    if ($cliente) {
      echo json_encode($cliente);
    } else {
      http_response_code(404);
      echo json_encode(['error' => 'No encontrado']);
    }
  } else {
    // Obtener TODOS los clientes
    $stmt = $pdo->query('SELECT * FROM clientes ORDER BY nombre');
    echo json_encode($stmt->fetchAll());
  }
}

// Con filtro (ej: pólizas de un cliente)
function getPolizas() {
  global $pdo;
  $clienteId = $_GET['cliente_id'] ?? null;

  if ($clienteId) {
    $stmt = $pdo->prepare('SELECT * FROM polizas WHERE cliente_id = ? ORDER BY fecha DESC');
    $stmt->execute([$clienteId]);
  } else {
    $stmt = $pdo->query('SELECT * FROM polizas ORDER BY fecha DESC');
  }
  echo json_encode($stmt->fetchAll());
}
POST — crear registro
function createCliente($data) {
  global $pdo;

  // Validar campos obligatorios
  if (empty($data['nombre'])) {
    http_response_code(400);
    echo json_encode(['error' => 'El nombre es obligatorio']);
    return;
  }

  $stmt = $pdo->prepare('
    INSERT INTO clientes (nombre, apellidos, telefono, localidad, cp, provincia, tipo)
    VALUES (:nombre, :apellidos, :telefono, :localidad, :cp, :provincia, :tipo)
  ');

  $stmt->execute([
    ':nombre'    => $data['nombre'],
    ':apellidos' => $data['apellidos'] ?? '',
    ':telefono'  => $data['telefono']  ?? '',
    ':localidad' => $data['localidad'] ?? '',
    ':cp'        => $data['cp']        ?? '',
    ':provincia' => $data['provincia'] ?? '',
    ':tipo'      => $data['tipo']      ?? 'particular',
  ]);

  // Devuelve el nuevo ID generado
  http_response_code(201);
  echo json_encode([
    'success' => true,
    'id'      => $pdo->lastInsertId()
  ]);
}
PUT — actualizar registro
function updateCliente($data, $id) {
  global $pdo;

  if (!$id) {
    http_response_code(400);
    echo json_encode(['error' => 'ID requerido']);
    return;
  }

  $stmt = $pdo->prepare('
    UPDATE clientes
    SET nombre=:nombre, apellidos=:apellidos, telefono=:telefono,
        localidad=:localidad, cp=:cp, provincia=:provincia, tipo=:tipo
    WHERE id=:id
  ');

  $stmt->execute([
    ':nombre'    => $data['nombre'],
    ':apellidos' => $data['apellidos'] ?? '',
    ':telefono'  => $data['telefono']  ?? '',
    ':localidad' => $data['localidad'] ?? '',
    ':cp'        => $data['cp']        ?? '',
    ':provincia' => $data['provincia'] ?? '',
    ':tipo'      => $data['tipo']      ?? 'particular',
    ':id'        => $id
  ]);

  echo json_encode(['success' => true]);
}
DELETE — eliminar registro
function deleteCliente($id) {
  global $pdo;

  if (!$id) {
    http_response_code(400);
    echo json_encode(['error' => 'ID requerido']);
    return;
  }

  $stmt = $pdo->prepare('DELETE FROM clientes WHERE id = ?');
  $stmt->execute([$id]);

  if ($stmt->rowCount() > 0) {
    echo json_encode(['success' => true]);
  } else {
    http_response_code(404);
    echo json_encode(['error' => 'No encontrado']);
  }
}

Vue ↔ PHP — cómo hablan entre sí
Métodos fetch en Vue para cada operación CRUD
🔗 URL base: Si tu proyecto está en http://localhost/mi-examen/, tus APIs están en http://localhost/mi-examen/clientes.php. Define una constante al inicio del script Vue.
Definir la URL base y cargar datos al inicio
new Vue({
  el: '#app',

  data: {
    // URL base de tu API (ajusta al nombre de tu carpeta)
    apiBase: 'http://localhost/mi-examen',
    clientes: [],
    // ... resto de data
  },

  // mounted() se ejecuta cuando Vue termina de inicializarse
  // Aquí es donde cargas los datos iniciales desde PHP
  mounted() {
    this.cargarClientes();
  },

  methods: {
    // ── CARGAR (GET) ──────────────────────────────
    async cargarClientes() {
      try {
        const res  = await fetch(`${this.apiBase}/clientes.php`);
        const data = await res.json();
        if (data.error) throw new Error(data.error);
        this.clientes = data;            // Array de clientes
      } catch(e) {
        alert('Error cargando clientes: ' + e.message);
      }
    },

    // ── CARGAR pólizas de un cliente ──────────────
    async cargarPolizas(clienteId) {
      const res  = await fetch(`${this.apiBase}/polizas.php?cliente_id=${clienteId}`);
      const data = await res.json();
      this.polizas = data;
    }
  }
});
Crear, Editar y Borrar con fetch
// ── CREAR (POST) ──────────────────────────────
async guardarCliente() {
  if (!this.fCliente.nombre) { alert('Nombre obligatorio'); return; }

  const esNuevo = this.modo === 'nuevo';

  const res = await fetch(
    esNuevo
      ? `${this.apiBase}/clientes.php`
      : `${this.apiBase}/clientes.php?id=${this.fCliente.id}`,
    {
      method:  esNuevo ? 'POST' : 'PUT',
      headers: { 'Content-Type': 'application/json' },
      body:    JSON.stringify(this.fCliente)
    }
  );

  const data = await res.json();

  if (data.error) { alert(data.error); return; }

  $('#modalCliente').modal('hide');
  await this.cargarClientes();    // Recarga la tabla desde BD
  this.ok('Cliente guardado');
},

// ── BORRAR (DELETE) ───────────────────────────
async borrarCliente(id) {
  if (!confirm('¿Eliminar cliente?')) return;

  const res  = await fetch(`${this.apiBase}/clientes.php?id=${id}`, {
    method: 'DELETE'
  });
  const data = await res.json();

  if (data.error) { alert(data.error); return; }

  await this.cargarClientes();
  this.ok('Cliente eliminado');
},

// ── LOGIN con PHP ─────────────────────────────
async hacerLogin() {
  const res = await fetch(`${this.apiBase}/login.php`, {
    method:  'POST',
    headers: { 'Content-Type': 'application/json' },
    body:    JSON.stringify({
      usuario:  this.loginUsuario,
      password: this.loginPassword
    })
  });
  const data = await res.json();

  if (data.error) {
    this.errorLogin = data.error;
  } else {
    this.usuarioLogueado = data.usuario;
    this.errorLogin = '';
    await this.cargarClientes();   // Carga datos al entrar
  }
}

OperaciónSolo Vue (sin BD)Vue + PHP + MySQL

Editar registro this.$set(array, i, obj) fetch PUT → cargarClientes()
Borrar registro this.clientes.filter(...) fetch DELETE → cargarClientes()
Cargar datos Ya están en data: {} mounted() → fetch GET
IDs Math.max(0, ...ids) + 1 Los genera MySQL automáticamente (AUTO_INCREMENT)

JavaScript — login sin BD (datos en data)
usuarios: [{ id:1, usuario:'admin', password:'1234', nombre:'Administrador' }],

methods: {
  hacerLogin() {
    const u = this.usuarios.find(u =>
      u.usuario === this.loginUsuario && u.password === this.loginPassword
    );
    if (u) { this.usuarioLogueado = u; this.errorLogin = ''; }
    else   { this.errorLogin = 'Usuario o contraseña incorrectos'; }
  },
  cerrarSesion() {
    this.usuarioLogueado = null;
    this.loginUsuario = this.loginPassword = '';
  }
}

JavaScript — computed buscador
computed: {
  clientesFiltrados() {
    if (!this.busqueda) return this.clientes;
    const b = this.busqueda.toLowerCase();
    return this.clientes.filter(c =>
      c.nombre.toLowerCase().includes(b)    ||
      c.apellidos.toLowerCase().includes(b) ||
      c.localidad.toLowerCase().includes(b)
    );
  }
}

JavaScript — métodos CRUD (sin BD)
methods: {
  nuevoCliente() {
    this.modo = 'nuevo';
    this.fCliente = { id:null, nombre:'', apellidos:'', telefono:'',
                      localidad:'', cp:'', provincia:'', tipo:'particular' };
    $('#modalCliente').modal('show');
  },

  editarCliente(c) {
    this.modo = 'editar';
    this.fCliente = { ...c };
    $('#modalCliente').modal('show');
  },

  guardarCliente() {
    if (!this.fCliente.nombre) { alert('Nombre obligatorio'); return; }

    if (this.modo === 'nuevo') {
      this.fCliente.id = Math.max(0, ...this.clientes.map(c => c.id)) + 1;
      this.clientes.push({ ...this.fCliente });
    } else {
      const i = this.clientes.findIndex(c => c.id === this.fCliente.id);
      this.$set(this.clientes, i, { ...this.fCliente });
    }
    $('#modalCliente').modal('hide');
    this.ok('Guardado');
  },

  borrarCliente(id) {
    if (!confirm('¿Eliminar?')) return;
    this.clientes = this.clientes.filter(c => c.id !== id);
  }
}

Pagos / Sub-items
Control de cuotas o pagos vinculados a una póliza
JavaScript — computed de pagos
computed: {
  pagosPoliza() {
    if (!this.polizaActual) return [];
    return this.pagos.filter(p => p.polizaId === this.polizaActual.id);
  },
  totalPagado() {
    return this.pagosPoliza.reduce((acc, p) => acc + p.importe, 0);
  },
  restante() {
    if (!this.polizaActual) return 0;
    return this.polizaActual.importe - this.totalPagado;
  }
},
methods: {
  agregarPago() {
    if (this.fPago.importe <= 0)              { alert('Importe inválido'); return; }
    if (this.fPago.importe > this.restante) { alert(`Máximo: ${this.restante}€`); return; }
    const id = Math.max(0, ...this.pagos.map(p => p.id)) + 1;
    this.pagos.push({ id, ...this.fPago });
    this.fPago.importe = 0; this.fPago.fecha = '';
  }
}
Colores por estado
Pintar filas y badges según el estado del registro
JavaScript — métodos de color
methods: {
  colorFila(estado) {
    const c = { 'cobrada':'success', 'a cuenta':'warning',
                 'liquidada':'info', 'anulada':'danger', 'pre-anulada':'active' };
    return c[estado] || '';
  },
  badgeEstado(estado) {
    const b = { 'cobrada':'label label-success', 'a cuenta':'label label-warning',
                 'liquidada':'label label-info', 'anulada':'label label-danger' };
    return b[estado] || 'label label-default';
  }
}

Esquema mental para el examen
Lee el enunciado, identifica cada bloque, construye en orden
📋 Regla de oro: Sigue siempre este orden. Si saltas pasos, perderás tiempo depurando errores innecesarios.
1
Lee el enunciado ENTERO antes de escribir código CRÍTICO
Identifica: ¿hay BD? ¿hay login? ¿cuántas entidades? ¿estados? ¿pagos? Anótalo en papel.
2
Setup de archivos
Si hay BD: carpeta en htdocs, XAMPP on, crear BD en phpMyAdmin, crear conexion.php y probarlo. Si no hay BD: solo index.html.
3
Pega la plantilla HTML base
Copia de esta guía → pega → abre en navegador → confirma que carga sin errores.
4
Rellena el data: {} completo
Arrays con ejemplos, objetos de formulario fX, variables de navegación, mensajeOk, etc. Si hay BD, añade también apiBase.
5
Si hay BD: crea los PHP y el mounted()
Un PHP por entidad. Empieza por el GET. Prueba que los datos llegan a Vue antes de hacer el HTML.
6
Login → Navbar → Tablas → CRUD → Detalle → Pagos → Colores
En este orden. Prueba cada paso en el navegador antes de continuar.
💡 Reglas de supervivencia
  • → Primero haz que funcione, luego ponlo bonito
  • → Cada vez que añadas algo, prueba en el navegador
  • → Si Vue no reacciona a cambios: usa this.$set() o .splice()
  • → Si el modal no abre: jQuery debe estar cargado ANTES que Bootstrap
  • → Si el fetch devuelve error: abre el PHP directamente en el navegador para ver qué devuelve
  • → Si PHP da error CORS: asegúrate de que tiene los headers Access-Control-Allow-Origin: *
  • → {{ variable }} en el HTML te sirve para ver valores mientras depuras
