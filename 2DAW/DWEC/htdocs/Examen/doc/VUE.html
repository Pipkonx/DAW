Estructura del proyecto
Lo primero que haces al sentarte: crear UN solo fichero .html
✅ Buena noticia: Vue 2 sin build tools = un único fichero .html. No hay carpetas raras, no hay npm install, no hay webpack. Solo abres el bloc de notas y empiezas.
📁 ¿Qué debes crear?
1
Crea una carpeta con el nombre de tu práctica
Ejemplo: mi-examen/ — Esto es solo para organizarte tú
2
Dentro, crea UN fichero: index.html
Solo este fichero. No necesitas más. Ni CSS separado, ni JS separado.
3
Ábrelo con VS Code o el editor que uses
Cuando termines, lo abres directamente en el navegador (doble clic o botón derecho → Abrir con Chrome)
🗂️ Así queda tu "proyecto"
📁 mi-examen/
└── 📄 index.html        ← TODO va aquí dentro

Dentro de ese index.html irá: el HTML, el CSS (en una etiqueta <style>) y el JavaScript de Vue (en una etiqueta <script>). Las librerías (Bootstrap, jQuery, Vue) se cargan desde internet mediante sus CDN — no hay que descargar nada.

🧠 Cómo funciona esto por dentro (simplificado)
Tu HTML — la estructura visible (botones, tablas, formularios)
Bootstrap — estilos y componentes listos (se carga de internet con <link>)
jQuery — necesario para que Bootstrap funcione (se carga de internet con <script>)
Vue 2 — la magia: mantiene los datos sincronizados con lo que se ve (se carga de internet con <script>)
Tu <script> — donde escribes los datos y la lógica de tu app
⚠️ Orden importa: Los <script> deben ir al final del <body>, y en este orden: jQuery → Bootstrap → Vue → Tu código. Si los pones en otro orden, nada funcionará y no sabrás por qué.

📋 Regla de oro: Sigue siempre este orden. Si vas a la pantalla de tabla antes de tener los datos, perderás tiempo depurando errores innecesarios.

JavaScript — método hacerLogin y cerrarSesion 
methods: {
  hacerLogin() {
    // Busca un usuario que tenga ese usuario Y contraseña
    const u = this.usuarios.find(u =>
      u.usuario === this.loginUsuario &&
      u.password === this.loginPassword
    );

    if (u) {
      this.usuarioLogueado = u;   // Guarda el usuario
      this.errorLogin = '';      // Limpia el error
      // Si tienes pantallas, ve a la principal:
      // this.pantalla = 'clientes';
    } else {
      this.errorLogin = 'Usuario o contraseña incorrectos';
    }
  },

  cerrarSesion() {
    this.usuarioLogueado = null;
    this.loginUsuario = '';
    this.loginPassword = '';
  }
}

JavaScript — computed para el buscador
computed = valor que Vue recalcula automáticamente cuando cambia busqueda. No necesitas llamarlo: simplemente usas clientesFiltrados en el HTML y funciona solo. 
computed: {
  clientesFiltrados() {
    // Si no hay texto escrito, devuelve todos
    if (!this.busqueda) return this.clientes;

    // Convierte a minúsculas para que no importe si escribes
    // "juan" o "JUAN" o "Juan"
    const b = this.busqueda.toLowerCase();

    return this.clientes.filter(c =>
      c.nombre.toLowerCase().includes(b)    ||
      c.apellidos.toLowerCase().includes(b) ||
      c.localidad.toLowerCase().includes(b) ||
      c.telefono.includes(b)  // Teléfono no necesita toLowerCase
    );
  }
}

JavaScript — métodos CRUD completos
methods: {

  // ── NUEVO: resetea el formulario y abre el modal ──
  nuevoCliente() {
    this.modo = 'nuevo';
    // Vaciar todos los campos
    this.fCliente = { id:null, nombre:'', apellidos:'', telefono:'',
                      localidad:'', cp:'', provincia:'', tipo:'particular' };
    $('#modalCliente').modal('show');   // jQuery abre el modal
  },

  // ── EDITAR: copia los datos al formulario y abre el modal ──
  editarCliente(cliente) {
    this.modo = 'editar';
    // { ...cliente } hace UNA COPIA (si modificas el form, no modificas el original)
    this.fCliente = { ...cliente };
    $('#modalCliente').modal('show');
  },

  // ── GUARDAR: decide si crear o actualizar ──
  guardarCliente() {
    // Validación básica (nunca guardes sin validar)
    if (!this.fCliente.nombre || !this.fCliente.apellidos) {
      alert('Nombre y Apellidos son obligatorios');
      return;  // Para aquí, no guarda
    }

    if (this.modo === 'nuevo') {
      // Calcula el próximo ID (el mayor que haya + 1)
      this.fCliente.id = Math.max(0, ...this.clientes.map(c => c.id)) + 1;
      // Añade una copia al array
      this.clientes.push({ ...this.fCliente });

    } else {
      // Encuentra la posición del elemento a editar
      const i = this.clientes.findIndex(c => c.id === this.fCliente.id);
      // $set garantiza que Vue detecta el cambio y actualiza la pantalla
      this.$set(this.clientes, i, { ...this.fCliente });
    }

    $('#modalCliente').modal('hide');   // Cierra el modal
    this.ok('Cliente guardado correctamente');
  },

  // ── BORRAR ──
  borrarCliente(id) {
    if (!confirm('¿Eliminar este cliente?')) return;
    // filter crea un nuevo array sin el elemento con ese id
    this.clientes = this.clientes.filter(c => c.id !== id);
  },

  // Función auxiliar para mensajes de éxito
  ok(msg) {
    this.mensajeOk = msg;
    setTimeout(() => this.mensajeOk = '', 3000);  // Desaparece en 3 seg
  }
}

Pagos / Sub-items
Control de cuotas o pagos vinculados a una póliza
JavaScript — computed de pagos
computed: {
  // Pagos de la póliza que está seleccionada
  pagosPoliza() {
    if (!this.polizaActual) return [];
    return this.pagos.filter(p => p.polizaId === this.polizaActual.id);
  },

  // Suma de todos los pagos de esa póliza
  totalPagado() {
    return this.pagosPoliza.reduce((acc, p) => acc + p.importe, 0);
  },

  // Cuánto queda por pagar
  restante() {
    if (!this.polizaActual) return 0;
    return this.polizaActual.importe - this.totalPagado;
  }
},

methods: {
  verPagos(poliza) {
    this.polizaActual = poliza;
    this.fPago = { polizaId: poliza.id, fecha: '', importe: 0 };
  },

  agregarPago() {
    if (this.fPago.importe <= 0)              { alert('Importe inválido'); return; }
    if (this.fPago.importe > this.restante) { alert(`Máximo: ${this.restante}€`); return; }
    if (!this.fPago.fecha)                    { alert('Indica una fecha'); return; }

    const id = Math.max(0, ...this.pagos.map(p => p.id)) + 1;
    this.pagos.push({ id, ...this.fPago });
    this.fPago.fecha = '';
    this.fPago.importe = 0;
  },

  borrarPago(id) {
    if (!confirm('¿Eliminar pago?')) return;
    this.pagos = this.pagos.filter(p => p.id !== id);
  }
}

Colores por estado
Cómo pintar filas de tabla y badges según el estado de un registro
JavaScript — métodos de color
methods: {
  // Devuelve la clase de Bootstrap para colorear la FILA completa
  // Úsalo en: :class="colorFila(poliza.estado)"
  colorFila(estado) {
    const colores = {
      'cobrada':     'success',   // Verde
      'a cuenta':    'warning',   // Amarillo
      'liquidada':   'info',      // Azul claro
      'anulada':     'danger',    // Rojo
      'pre-anulada': 'active'     // Gris
    };
    // Si no encuentra el estado, devuelve '' (sin color)
    return colores[estado] || '';
  },

  // Devuelve la clase para el BADGE pequeño de estado
  // Úsalo en: :class="badgeEstado(poliza.estado)"
  badgeEstado(estado) {
    const badges = {
      'cobrada':     'label label-success',
      'a cuenta':    'label label-warning',
      'liquidada':   'label label-info',
      'anulada':     'label label-danger',
      'pre-anulada': 'label label-default'
    };
    return badges[estado] || 'label label-default';
  }
}

computed: {
  polizasFiltradas() {
    // 1. Copia y ordena por fecha descendente
    let lista = [...this.polizas].sort(
      (a, b) => new Date(b.fecha) - new Date(a.fecha)
    );
    // 2. Filtra por estado si hay alguno seleccionado
    if (this.filtroEstado) {
      lista = lista.filter(p => p.estado === this.filtroEstado);
    }
